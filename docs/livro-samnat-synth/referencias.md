## Como citar e manter este livro

Use links diretos a manuais e documentação oficiais. Registre data de acesso quando uma edição impressa exigir bibliografia formal. Para alegações sobre um modelo de instrumento, cite o manual daquele modelo. Não extrapole uma característica de um modelo para todos os sintetizadores do fabricante.
